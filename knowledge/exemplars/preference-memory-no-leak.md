# Exemplar 6 — User preference memory that must not leak

Status: PROPOSED — Phase 8 exemplar knowledge record
Inherits: `standard.knowledge.common_constraints@0.1`

**Proves:** the personal-to-organisational contamination boundary, and why preference memory is never canonical anywhere.

## Identity
- Knowledge ID: `knowledge.reporting_convention.personal_working_preference`
- Version: 3
- Subject: an individual's preferred presentation conventions for draft financial output
- Scope: `PERSONAL/<human>` — a separate scope family, not a level of the organisational tree
- Memory class: `PREFERENCE_MEMORY`
- Origin: `HUMAN_ORIGIN`
- Sensitivity: `INTERNAL`

## Statement
This person prefers drafts presented in a stated layout, rounding and ordering.

## Epistemic type / governance state
It is a preference. On the epistemic axis it is closest to a `FACT_CLAIM` **about a person's preference** — and that is exactly as far as it goes. It has no governance state above `APPROVED` and never will.

## Three boundaries, all live here
1. **Never canonical, anywhere** (`knowledge/memory-class-model.md` §4). Promoting it would give a convention the standing of an evidenced position, citable as one.
2. **Never leaves `PERSONAL` scope by absorption.** Reaching an organisational scope requires a governed transfer producing a new organisationally-owned record with its own basis.
3. **Never overrides fact, evidence, canonical knowledge or law.** Where the preference is to round to whole millions and the funder's template requires thousands, the preference loses without a contest.

## The failure mode this names
Preference leakage is quiet and cumulative. A convention appears in enough drafts that it starts to look like the house standard; then a new person adopts it because it is what they see; then it is cited as "how we do it" with nobody able to say who decided. Each step is reasonable. The result is an unowned organisational rule that no evidence supports and no one can revise, because nobody knows what it rests on.

## The legitimate route
If the convention genuinely should bind, it is **not a preference**. It becomes a `PROCEDURAL_MEMORY` method, adopted at organisational scope by a governed act, with the adopting decision as its evidence. That route is open. What is refused is arriving there by accumulation.
