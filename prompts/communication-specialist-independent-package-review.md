Verify that the package does not collapse:

`ROLE != AGENT INSTANCE != MODEL != MODEL PROFILE != ROUTER != ORCHESTRATOR != WORKFLOW != REVIEW PROFILE != REVIEW INSTANCE != DECISION RIGHT != DECISION RECORD != KNOWLEDGE != CANONICAL RECORD != HUMAN AUTHORITY`

- `jefferson-fisher-communication` and `Fisher Mode` are compatibility aliases only;
- `Calm Direct Mode` / `Communication Control Filter` are product/methodology constructs, not authority-bearing identities;
- runtime prompt assembly is derived from governed registry objects, not a competing source of truth.

### 2. Positioning / provenance / impersonation boundary

Verify package-wide consistency of:
- no impersonation;
- no endorsement / licensing / training / approval claim;
