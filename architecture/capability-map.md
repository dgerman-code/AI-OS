## Architecture rule

A role should be first-class only when at least one of the following is true:

- it requires a distinct professional methodology;
- it has a distinct authority boundary;
- it requires independent review;
- it regularly produces a standalone professional artifact.

Otherwise the capability should usually be represented as a reusable skill pack or specialisation.
